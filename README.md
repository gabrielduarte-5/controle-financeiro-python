# Sistema de Controle Financeiro Pessoal

## Sobre o projeto
Criei este projeto em Python para aplicar meus conhecimentos de lógica de programação em uma situação relacionada à organização financeira.

Minha ideia foi desenvolver um sistema simples para registrar receitas e despesas, acompanhar o saldo disponível e consultar as movimentações realizadas.

## Funcionalidades
- Registrar receitas.
- Registrar despesas.
- Consultar o saldo disponível.
- Visualizar o histórico de movimentações.
- Calcular o total de receitas e despesas.
- Excluir movimentações registradas.
- Consultar um resumo financeiro.

## Conhecimentos utilizados
Python, listas, variáveis, operações matemáticas, estruturas condicionais (`if`, `elif`, `else`) e estruturas de repetição (`while`, `for`).

## Como executar
Execute o arquivo Python do projeto em um ambiente com Python 3 instalado.

**Observação:** Projeto acadêmico desenvolvido para praticar manipulação de listas, cálculos e organização de informações financeiras.
